One original fortune-cookie line for a software developer, written by a
deterministic Python 3.13 stdlib-only program (`main.py`) to
`/output/entry.txt`.

> The code nobody owns is the code that owns you.

The line is about orphaned code: the module nobody maintains, nobody
reviews, nobody dares to touch — and how it ends up dictating your days
instead of the other way around. *Owns* cuts both ways: nobody owns it,
yet it owns you.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Two runs write byte-identical output (sha256
`ea06089b103a0f284b6b0c2196e01e1921e6ea280238ba38bc7358f0cf3934ff`).
